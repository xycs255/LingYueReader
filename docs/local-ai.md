# 本地 AI

> 状态：已支持手机本机模型和局域网模型。手机模型首次下载需要网络；安装后在手机上推理。局域网模型由用户在自己的电脑上运行，灵阅通过局域网调用。两种方式都不需要付费云接口。

## 选择方式

在“我的 → AI 服务”启用 AI 后，选择“本机模型（离线）”或“局域网模型”。阅读 AI 和写作 AI 共用这项配置。

| 方式 | 当前实现 | 适用情况 |
| --- | --- | --- |
| 手机本机 | MediaPipe LLM Inference 加载 `.task` 模型；需要支持 `arm64-v8a` 的手机 | 不连电脑的短篇解释、润色、挑错和简短续写 |
| 局域网 | 通过兼容 OpenAI 聊天接口的服务连接电脑上的 Ollama、LM Studio 等 | 电脑有足够资源、希望使用较大模型或写作设定包工具 |

## 手机本机模型

应用提供两个 Qwen2.5 预设下载项：1.5B 的文件约 1.6 GB、上下文上限 4096 token；0.5B 的文件约 550 MB、上下文上限 1280 token。1.5B 建议在 8 GB 内存以上的手机使用。预设下载支持续传，并在安装前核对 SHA-256。也可以从系统文件选择器导入兼容的 `.task` 文件；导入时会**复制到应用的模型目录**。自选模型的真实上下文长度无法自动获知，当前按 4096 token 处理，仍须以模型本身的限制为准。

模型文件不随 APK 分发。本机推理不发送书籍或写作内容到服务器；下载预设模型时会访问模型托管站点。长输入会按上下文预算截短，因此小模型处理整章、长对话或复杂写作资料时可能遗漏信息。速度、耗电和能否成功载入取决于设备与模型，尚无统一的实测保证。

## 局域网模型

在电脑启动兼容 OpenAI 接口的服务，填入电脑的局域网地址和实际加载的模型名。Ollama 的常见地址是 `http://电脑IP:11434/v1`，LM Studio 是 `http://电脑IP:1234/v1`；服务必须监听局域网地址，例如 Ollama 可设置 `OLLAMA_HOST=0.0.0.0`。局域网地址允许使用 HTTP 且密钥可以留空；公网地址要求 HTTPS 和密钥。灵阅将请求内容发送给所填的服务器，使用前应确认电脑、网络和模型服务可信。

局域网预设在应用中使用 32,000 token 的上下文预算，这是灵阅的配置值，**不代表**所连接模型或服务一定支持该长度。写作设定包的查询与“整理本章”走兼容接口的工具调用；实际能否完成，还取决于服务的工具调用兼容性、模型能力和上下文容量。

## 现有能力边界

阅读 AI 已有解释选文、AI 释义、前情提要、问这本书、人物表等入口，写作 AI 也可调用当前选定的模型。生成内容需要读者核对，尤其是人名、事实和引文。本机模型上下文短，写作时只带按章精选的资料，**不能**使用完整设定包工具、需要工具核对资料的项目写作流程或“整理本章”；这些任务会明确提示改用支持工具调用的局域网模型或其他兼容服务，普通短段润色与续写仍可在本机运行。

目前没有集成 llama.cpp、GGUF 导入、JNI 推理或通过文件描述符直接 mmap 模型文件。它们仅可作为未来方案评估，不能按已实现功能使用。
