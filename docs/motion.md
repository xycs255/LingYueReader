# 灵阅动效规范

代码里的取值都在 `app/src/main/java/com/xycs/lingyuereader/ui/Motion.kt`，新加的动画从那里取，不要另写数字。

## 原则

1. **有来处**：东西从哪里来就从哪里出现。书从封面放大打开、缩回封面；新主题从手指点的地方扩散开；浮层从它贴着的那条边升起。
2. **跟手**：能拖的都用弹簧（翻页、导航栏、捏合字号），松手顺着当时的速度走，不突然停住。
3. **短**：大多数动画在 0.15–0.42 秒内结束。读书时不打扰：翻页、滚动只做必要的移动，不加装饰。
4. **可以关**：墨水屏 / 省电模式下所有动画直接跳到终态；系统里关了动画（无障碍“移除动画”或动画时长缩放为 0）时也一样，但玻璃和配色照旧（WCAG 2.3.3）。主题设置里还可以单独把页面切换改成“无”。

## 基本取值

| 名称 | 取值 | 用在 |
| --- | --- | --- |
| `SHORT` | 150 ms | 小元素出现、颜色变化、离场 |
| `MEDIUM` | 280 ms | 浮层、卡片、列表项 |
| `LONG` | 420 ms | 整页切换、打开书 |
| `REVEAL` | 560 ms | 换主题的圆形扩散 |
| `TURN` | 300 ms | 点按 / 音量键翻页、滚一屏 |
| 标准缓动 `Standard` | cubic-bezier(0.2, 0, 0, 1) | 屏幕内的移动 |
| 强调缓动 `Emphasized` | cubic-bezier(0.05, 0.7, 0.1, 1) | 进场：一下冲出、慢慢停稳 |
| 离场缓动 `Exit` | cubic-bezier(0.3, 0, 0.8, 0.15) | 离场：慢起步、加速离开 |
| `press()` | 弹簧，阻尼 0.6，刚度中等 | 按下缩小、松手回弹 |
| `pop()` | 弹簧，阻尼 0.55，刚度 500 | 气泡、选中圈弹出 |
| `settle()` | 弹簧，无回弹 | 跟手的东西松手归位 |
| `listItem()` | 弹簧，无回弹，刚度中低 | 列表增删、换位 |

## 页面

| 场景 | 动效 |
| --- | --- |
| 书架 → 阅读 | 阅读页从封面中心、封面大小放大到全屏（强调缓动 420 ms，前 150 ms 淡入）；书架放大到 1.06 倍并淡出，像往后退 |
| 阅读 → 书架 | 反过来：阅读页缩回那本书的封面，最后 150 ms 淡出；书架从 1.06 倍回到原大小；缩回去的阅读页在上面 |
| 进入下一层（层级滑动，默认） | 新页从右边整页推入；上一层往左退 1/4，透明度降到 0.35 |
| 返回上一层 | 反过来，离开的一页在上面、向右滑出 |
| 淡入淡出 | 新页从 0.97 倍放大并淡入，旧页 150 ms 淡出 |
| 首页四个标签 | 导航栏液态玻璃指示器跟手拖动，页面用弹簧滚到目标页 |

## 组件

| 组件 | 动效 |
| --- | --- |
| 封面、书架列表行、卡片 | 按下下沉（miuix Sink），松手回弹 |
| 选项片（翻页方式、繁简、方向、深浅色按钮） | 按下缩到 0.93–0.95 倍，选中的底色和字色 150 ms 渐变 |
| 强调色圆点 | 按下缩到 0.88 倍；选中外圈用 `pop()` 弹出 |
| 书架、生词本列表 | 排序、分组筛选、删除、标为掌握时，其余项滑到新位置，新项淡入、删掉的淡出 |
| 换主题（深浅色、强调色、Monet、配色风格） | 先拍下当前画面盖住，换好后从手指点的地方挖一个越来越大的圆，新主题从圆里露出（560 ms，强调缓动） |

## 阅读页

| 场景 | 动效 |
| --- | --- |
| 菜单栏、控制条 | 从各自那条边滑入（强调缓动 280 ms）+ 150 ms 淡入；收起时离场缓动 |
| 听书条、自动滚动条 | 从页底升起一半高度并淡入 |
| “回到刚才” | 从页底升起，0.9 倍弹到原大小 |
| 选字操作条 | 出现时从 0.9 倍弹到原大小并淡入 |
| 捏合调字号 | 中间弹出气泡，里面的“永”字随手指实时变大变小；松手气泡缩小淡出，再重新排版 |
| 翻页 | 平移、覆盖、仿真都跟手；仿真的书页绕圆柱卷起（半径最大为短边的 1/8，刚拉动时随拉开的距离从 0 长起来），翻完正好整页离开屏幕；“无动画”拖动时书页不动，松手停稳后直接换页；点按、音量键翻页统一 300 ms 标准缓动（`TURN`，依据 Klein 与 Bederson 2005：300 ms 动画让阅读任务出错率最多降 54%）。不加额外装饰 |
| 滚动模式点一下 | 按能看清的那段（去掉状态栏、状态行）翻，再少翻一行半，300 ms；翻完在原来的底边划一道短横线（线上读过、线下接着读），0.5 s 后用 1.4 s 褪掉，手指一滚就消失 |
| 跳到书签 / 批注 / 搜索结果 / 回到刚才 | 落点那一段铺一层淡强调色，0.7 s 后用 1.6 s 褪掉；墨水屏上亮 2 s 后直接消失 |
| 全书进度细线、书页厚度 | 读到新位置时 280 ms 顺滑走过去 |
| 书页配色 | 环境光、日落变暖时 3 秒渐变，不突然一闪 |

## 生词本复习

| 场景 | 动效 |
| --- | --- |
| 看释义 | 卡片绕竖轴翻过去（420 ms），转过一半换成背面 |
| 下一个词 | 旧卡往左滑出淡出，新卡从右边半屏处滑入 |

## 统计

| 场景 | 动效 |
| --- | --- |
| 今天 / 本周 / 本月 / 今年 | 打开时数字从 0 往上数（900 ms） |
| 每日目标进度条、各本书时长条 | 从 0 长到实际长度 |
| 近 20 周热力图 | 从左往右一列列亮起来，每格从 0.6 倍放大到原大小 |

## 触感

| 场景 | 震动 |
| --- | --- |
| 长按选中一个词 | 长按（LongPress） |
| 长按书架上的书 | 长按（LongPress） |
| 捏合时字号每跨过一个整数 | 轻点（TextHandleMove） |
| 划选、拖把手时选区每变一格 | 轻点（TextHandleMove，同系统文本框） |
| 复习时点“记得” / “还不熟” | 确认（Confirm）/ 拒绝（Reject） |

翻页、滚动不震：一章要翻几十次，震多了反而烦。
