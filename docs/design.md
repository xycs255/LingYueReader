# 灵阅界面规范：选项与设置（miuix / HyperOS）

所有“选项”界面——阅读页的外观与设置面板、听书、目录、“我的”、主题设置、词典、书籍详情、统计里的目标——都照 HyperOS 的设置页来做，
用 miuix 自己的控件和配色，和系统设置看起来是一家。
组件都在 `app/src/main/java/com/xycs/lingyuereader/ui/Grouped.kt`，新加的选项从那里取，不要另写一套。动效取值见 `docs/motion.md`。

## 原则

1. **一张卡片一组**：相关的几项放进一张大圆角白卡片，卡片之间留白，卡片里不画分隔线，靠行高和留白分开。
2. **一行一件事**：左边名字（半粗），需要时下面一行灰色说明；右边灰色的当前值和小箭头。较长的解释写在卡片下面的灰色小字里。
3. **组名是卡片上方的灰色小字**（miuix `SmallTitle`，用次要文字色），可以没有。组名只是标签，不用强调色，也不拿来写状态（“正在试分章……”这类写在卡片里）。
4. **常用的放外面，其余点进去**：一屏放得下最常调的几样；其余按用途分页，从带“›”的行点进去，面板左上角是圆形返回钮。
5. **控件用 miuix 的**：
   - 开 / 关 → miuix 开关（打开是强调色）；
   - 二到五个互斥的短选项 → 分段控件（浅灰底槽，选中的那格白块、强调色字）；
   - 选项多、或需要说明 → 勾选列表（选中的名字变强调色、右边打勾）；
   - 选项不多、不想占地方 → 下拉选择（右边当前值和小箭头，点开弹出菜单）；
   - 连续的数值 → miuix 滑块（粗圆角条）；名字和值在上一行，滑块整宽在下一行；
   - 动作 → 强调色文字的一行；会删东西的用红色，单独成组放在最后；
   - 分段控件只放互斥的选项，不放“更多…”这种跳转——跳转用带“›”的行。
7. **每行左边写着是什么**：控件不光秃秃地叠在一起，字号、排版这类调节也是“名字 + 右边控件”的一行。
8. **空的时候说清楚**：书架、生词本、搜索还什么都没有时，页面中间一个圆底图标、一句标题、一两句说明，能做事的给一个按钮（`EmptyState`），不在左上角丢一行灰字。
9. **同级页面同样的头**：底栏四页（书架、生词本、统计、我的）都是大标题、名字和底栏标签一样，往上滚收成小标题。
6. **配色跟着 miuix**：浅色、深色、Monet、自选强调色都由 miuix 主题给。阅读页的面板从书页配色调出来（`readerGroupedColors`）：
   面板底比书页亮一点、卡片再亮一点，字用书页的字色——纸白页上是暖白面板，墨夜页上是深褐面板，不用 miuix 的冷灰和纯黑；
   没挑过强调色时跟着书页（朱砂 / 琥珀）。

## 各界面

### 阅读页（样稿：“灵阅阅读界面样稿”）

- 读书时屏幕上只有正文：顶上一行小字页眉（章名，跟着书页一起翻；章首页下面就是大字章名，不再写页眉），底下一根全书进度细线（强调色）和一行小字（左边章名；右边“第 N/M 页 · 本章余多久”，全屏时补上时间、电量）；
  两侧书口是两摞纸，只有几像素。
- 章首：序号（“第一章”）小字、强调色、字距拉开；章名大字半粗；下面一道 28dp 的短线。
- 配色：纸白底 `#F5F0E6`、字 `#2B2620`、次要 `#6F665A`、朱砂 `#B5432F`；墨夜底 `#191714`、字 `#D6CDBB`、次要 `#8E8676`、琥珀 `#E0905F`；另有宣黄、竹青、灰蓝。
- 加了书签的页，右上角垂下一条燕尾书签丝带。
- 点中间出菜单，都浮在书页上：
  - 顶上一条胶囊：返回、书名（下面作者 · 已读多少）、书签、书内搜索、更多（自动滚动 / 自动翻页、书籍详情）；
  - 底下一块：‹ 上一章 · 章名 · 下一章 ›、全书进度细线滑块（3dp 轨道、白色圆钮，左“全书 N%”、右“本章 X/Y 页”）、目录 / 听书 / 外观（衬线 Aa）/ 设置四格；
    菜单出来时页脚淡掉，不在底栏下面露半行字；打开目录、外观等面板时菜单收起。
- 选字后的操作条是一颗深色胶囊（墨色底、纸色字）：查词 | 划线 | 批注 | 复制 | 卡片；“划线”直接用黄色划上，“批注”打开面板，点书页别处收起。
- 查词先弹小卡片：词和读音大字，右上角划线、收入生词本（星），下面头几条释义和原句，最底下汉典、百度汉语和“完整释义 ›”；展开后是整页的分组查词面板。
- 目录：小书封、书名、作者 · 已读 · 还剩约多久，右上角关闭；分段控件切换目录 / 书签 / 批注；每章一行：序号、宋体章名、右边要读多久，正在读的那章铺一层淡强调色，写“正在读 · N%”。
- 面板的强调色：没在主题设置里挑过强调色、也没开 Monet 时，跟着书页走（朱砂 / 琥珀）。

### 阅读设置（面板）

- 菜单里的“外观”打开首页（标题“外观”，右上角“完成”），一张卡片一件事：
  - 亮度：两头太阳、灰色滑块，右边“自动”；
  - 背景：一排圆形书页配色（纸白、宣黄、竹青、灰蓝、墨夜、自定义）；
  - 文字：“字号”一行（右边小 A、字号、大 A 的步进器），“字体 ›”一行，“排版”一行（右边紧凑 / 标准 / 宽松分段）；
  - 最后“翻页方式 ›”“更多设置 ›”。
- 菜单里的“设置”直接打开“阅读设置”：字体、排版、翻页方式、繁简与注音；点按与按键、护眼、屏幕。
- 二级页：
  - 排版：预设（紧凑 / 标准 / 宽松）、行距、段距、字距、边距、段首空两格、两端对齐、恢复默认；
  - 翻页方式：勾选列表、书页厚度、横屏时双页；
  - 点按与按键：点按翻页、九格点按区域（预设：左右翻页 / 单手）、音量键翻页；
  - 护眼：跟随环境光、系统深色时用夜间背景、日落后逐渐变暖、远眺提醒；
  - 屏幕：全屏、屏幕常亮、方向、墨水屏 / 省电模式；
  - 字体、繁简与注音、自定义配色（选了“自定义”配色时出现）。
- 面板跟着内容高矮，最高到屏幕的 85%，内容多的页在里面滚动；换页时高度渐变过去。返回键先回首页，再关面板。

### 听书（面板）

进度一行、大号的上一句 / 播放 / 下一句；语速滑块；语音、定时关闭两个勾选列表。

### 查词、注释、书摘卡片（面板）

- 查词照苹果的“查询”：标题栏右边“管理词典”；词头大字，两边各一对小圆钮微调选区；
  下面一排三格操作（收入生词本、复制、划线·批注）；字典、词典、导入的词典、相关词语各一组，组下小字注明来源；
  最后一组“在线查询”（汉典、百度汉语、其他词典 App）。
- 注释：标题栏右边“完成”，注释正文用书里的字体放在一张卡片里。
- 书摘卡片：标题栏右边“分享”；预览图带阴影居中，下面是配色的分段控件和“保存图片”。

### 我的

大标题；阅读（词典、主题设置）；备份（备份书架、从备份恢复、自动备份到文件夹，开着时再有备份位置、现在备份一次）；关于（版本、项目主页）。每行都带彩色图标。

### 主题设置

照“显示与亮度”：三部小手机选外观（跟随系统 / 浅色 / 深色）；强调色圆点（一行，放不下左右滑，选中的打勾）、Monet 取色、配色风格；
效果（模糊、液态玻璃、悬浮底栏）；墨水屏；页面切换动画和界面缩放（名字和百分比一行，滑块一行）。每个开关的作用写在它自己下面。

### 词典

内置词典一个开关；导入的词典一行一本带开关；右上角“编辑”进入编辑状态，每行出现红色删除和上下移动。

### 书籍详情

左边封面、右边书名作者（格式 · 章数 · 字数，读到哪）；下面整宽的“开始 / 继续阅读”，和卡片左右对齐；简介；信息（累计阅读、添加于、最近阅读、来源文件）；操作；最后单独一组红色的“移除”。

### 书架

大标题“书架”，右上角搜索、导入、排序；一行三本。生成的封面是布面色块：左边一道书脊，上方衬线书名和一道短线，下方作者。
封面下面书名（两行）、进度小字，右边一个小“⋯”；长按封面也能出菜单。

### 统计

大标题“统计”；今天写大，本周 / 本月 / 今年并排小一号；每日目标（进度、“每天读”菜单选择、晚上提醒开关）；近 20 周热力图；各本书的时长。
