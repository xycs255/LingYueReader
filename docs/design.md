# 灵阅界面规范：纸张、紧凑控件与轻玻璃

书架、阅读、写作、生词本、统计和设置共用暖纸色与紧凑分组组件。阅读页把正文放在最前，导航与临时操作才使用低对比的玻璃浮层。
miuix 继续承担原生控件与交互；默认配色由 `paperAppColors` 提供，Monet 和自选强调色仍由 miuix 生成。
组件都在 `app/src/main/java/com/xycs/lingyuereader/ui/Grouped.kt`，新加的选项从那里取，不要另写一套。动效取值见 `docs/motion.md`。

## 原则

1. **一张卡片一组**：相关的几项放进一张暖白圆角卡片，卡片之间留白，卡片里不画分隔线，靠行高和留白分开。
2. **一行一件事**：左边名字（半粗），需要时下面一行灰色说明；右边灰色的当前值和小箭头。较长的解释写在卡片下面的灰色小字里。
3. **组名是卡片上方的灰色小字**（miuix `SmallTitle`，用次要文字色），可以没有。组名只是标签，不用强调色，也不拿来写状态（“正在试分章……”这类写在卡片里）。
4. **常用的放外面，其余点进去**：一屏放得下最常调的几样；其余按用途分页，从带“›”的行点进去，面板左上角是圆形返回钮。
5. **控件用 miuix 的**：
   - 开 / 关 → miuix 开关（打开是强调色）；
   - 二到五个互斥的短选项 → 分段控件（浅灰底槽，选中的那格白块、强调色字；深色是比底槽亮一档的深块，不用浅色块）；
   - 选项多、或需要说明 → 勾选列表（选中的名字变强调色、右边打勾）；
   - 选项不多、不想占地方 → 下拉选择（右边当前值和小箭头，点开弹出菜单）；
   - 连续的数值 → miuix 滑块（粗圆角条）；名字和值在上一行，滑块整宽在下一行；
   - 动作 → 强调色文字的一行；会删东西的用红色，单独成组放在最后；
   - 分段控件只放互斥的选项，不放“更多…”这种跳转——跳转用带“›”的行。
   - 其余的也从 `Grouped.kt` 取，不在页面里另画：
     - **主按钮**（`PrimaryButton`）：整宽、至少 48dp 高、14dp 圆角，强调色底配 `onTint` 的字（16sp 半粗）；删除类红底白字。一页最多一个，和下面的卡片左右对齐。
     - **胶囊按钮**（`PillButton`）：看着 36dp 高、两头全圆，能点的范围至少 48dp；三种样子——实心（强调色底，一排里最主要的那个）、淡色（淡强调色底、强调色字，如“复习 N”）、灰底（其余）。一排并列间距 8dp。
     - **标签**（`Tag`）：状态、类别的小徽标（“定稿”“错字”），12sp 字、6dp 圆角、字色的淡色底；颜色用下面的语义色，不另写。
       写作建议的五类标签（`SuggestTag`）颜色之外还带形状：● 错字（删除色）、▲ 设定（提醒色）、■ 规范（强调色）、◆ 口吻（紫）、★ AI 腔（青，“去 AI 腔”的结果），不只靠颜色分。
       编辑器正文里这五类的划线也一样不只靠颜色（`suggestLine`）：错字波浪线、设定双线、规范虚线、口吻点线、AI 腔点划线，用这类的颜色画在基线下方，底色照旧是这类颜色的淡色。
       青色和紫色一样，跟强调色、删除色、提醒色和另外几类撞了就转色相（`distinctFrom`），两两色差都 ≥ 15。
       本机标出的 AI 腔、黑名单命中和检查规则一样是提醒色底；光标点上去的一行用“AI 腔”“我的黑名单”标签（AI 腔的颜色）和作者自己的“规则”（提醒色）分开。
       线形是静止的，减少动效、墨水屏灰阶下照样分得出；划线按排版结果在绘制阶段画（`drawMarkLines`），只画看得见的几行，不改文字样式、不触发重排。
     - **对话框按钮行**（`DialogButtons`）：“取消”在左、确认在右，两键等宽；会删东西的确认键用红色。
     - **对话框里选一项**（`DialogOptionList`）：一行一项（名字，可带一行说明），点了就选，样子同勾选列表；不用一格格按钮拼。
       项要标“做过了”的（“AI 写”面板挑节拍）用 `MarkedOptionRow`：做过的左边成功色小勾、名字淡一点，名字最多两行；选中的仍是强调色字加右边打勾。
       要先选好再点确认的（“AI 写”面板），选项用 `MarkedOptionRow` 排成一组单选，下面是 `DialogButtons`；确认键不重复选项的名字（“开始写”“写第 N 拍”）。
       一个对话框里分几节时，节名用 `DialogSectionLabel`（次要色 13sp，和选项文字左对齐，读屏当标题念）。
     - **勾选框一行**（`CheckboxRow`）：可以各自勾、不互斥的清单（细纲卡的节拍“已写”）：左边 miuix 勾选框，勾上的名字变第三级灰；整行能点，读屏按勾选框念。当对话框里的选项开关用（“AI 写”面板的“出 3 个方向的版本”）时传 `dimChecked = false`，勾上不变灰；对当前选项不起作用时 `enabled = false`，说明里写清对哪几项有效。
     - **步进器**（`NumberStepper`）：章号这类小整数，“－ 数字 ＋”；两边 32dp 圆底灰钮、能点 48dp，中间的数字点一下直接输入（数字键盘），超出范围的收到边上。
       可以“不填”的，空着时中间是第三级灰的“不填”，－ 不能点、＋ 从起点开始，在最小值上再按 － 回到“不填”；到上限 ＋ 变灰。
       放在“名字 + 右边控件”的一行里（`LabeledRow`），不再用只收数字的文本框。
     - **横滑一排**（`FadingScrollRow`）：一行放不下、又要一格格对齐的（知情格）左右滑，哪边还有没露出来的，哪边边缘渐隐 28dp；放得下时不渐隐。
       胶囊少、能换行的（人物的状态方面、对话框里的常用选项）用 FlowRow 换行，不横着溢出、也不切掉最后一个。
     - **只显示的一行**（`InfoRow`）：名字，下面一行灰色说明，不能点（审稿页还没审时的三关）。
     - **加载 / 空 / 出错**：卡片里一行“正在……”用 `LoadingRow`（16dp 转圈 + 次要色字），整页用 `LoadingState`；卡片里的“还没有……”用 `EmptyRow`，整页用 `EmptyState`；
       出错用 `ErrorText`（删除色 14sp，写成“做什么没成：原因”，不加“出错了”前缀）。转圈一律用 `Spinner`，不直接用 miuix 的。
     - **编辑器浮层面板**（`InlinePanel`）：贴在键盘上方，顶上 20dp 圆角、卡片底色；标题行左边强调色小图标、右边和目录面板一样的圆底关闭钮（32dp，能点 48dp）；底下一排胶囊按钮。
       面板本身就是一组切换时（写作工具），用 `header` 把标题行换成铺满的分段控件，关闭钮留在它右端，不另起标题栏；标题只给读屏当面板名。
     - **工具格**（`ToolTileGrid`）：一格“20dp 强调色图标 + 12sp 短名字”，看着 52dp 高、12dp 圆角灰底；格子等宽铺满整行，一行放得下（每格不窄于 64dp，随字号放大）就排一行，放不下每行 4 格换行，不横向溢出、不在右边留空。每格的图标要互相分得开。
     - **在本页展开的一行**（`ExpandRow`）：名字、右边灰色的说明（“10 项”），小箭头收着朝右、展开朝下（标准缓动转过去，减少动效时直接换），读屏念“已展开 / 已收起”。
       只在本页多露几行次要选项时用（排版设置的“更多排版规则”）；整组不常调的、自成一页的用 `NavRow` 点进二级页（作品 AI 设置的“高级设置”）。
     - **带字图标按钮**（`LabeledIconButton`）：图标下面一行 10sp 小字（“AI”“书灵”“工具”），能点 48dp；开着时强调色，否则次要色；有读屏描述，长按给一句说明。只放得下图标、又不是一看就懂的地方用它，不留光秃秃的图标。
     - **二级页骨架**（`SubPageScaffold`）：玻璃小标题栏（左返回、右边操作，文字操作用 `BarTextAction`），设置页的浅灰底，提示条。
     - **面板标题栏**（`SheetNavBar`）、**名字 + 右边控件的一行**（`LabeledRow`）。
7. **每行左边写着是什么**：控件不光秃秃地叠在一起，字号、排版这类调节也是“名字 + 右边控件”的一行。
8. **空的时候说清楚**：书架、生词本、搜索还什么都没有时，页面中间一个圆底图标、一句标题、一两句说明，能做事的给一个按钮（`EmptyState`），不在左上角丢一行灰字。
9. **同级页面同样的头**：底栏五页（书架、写作、生词本、统计、我的）都是大标题、名字和底栏标签一样，往上滚收成小标题。
10. **删除**：能恢复的直接删，底下给一条带“撤销”的提示条（生词本）；不能恢复的先弹确认，确认键用红色（`DialogButtons(destructive = true)`），说清会删掉什么。
11. **配色在提供者里读**：`LocalGroupedColors` 没有默认值，在 `ProvideGroupedColors` / `ProvideReaderColors` 外面读会直接报错（以前默认给浅色，深色模式下黑字画在深灰卡片上也看不出来）。
    对话框、面板、菜单的内容画在最外层的弹层宿主里，拿不到页面里提供的配色：`GlassDialog`、`GlassSheet` 会把调用处的配色带进去，自己写弹层时在调用处读好再传。
6. **配色跟着选择**：默认浅色与深色使用暖纸、暖墨配色；Monet、自选强调色由 miuix 主题给。阅读页的面板从书页配色调出来（`readerGroupedColors`）：
   面板底比书页亮一点、卡片再亮一点，字用书页的字色——纸白页上是暖白面板，墨夜页上是深褐面板，不用 miuix 的冷灰和纯黑；
   没挑过强调色时跟着书页（朱砂 / 琥珀）。

| 名称 | 浅色 | 深色 | miuix 配色 | 用在 |
| --- | --- | --- | --- | --- |
| 页面底 | `#F6F2EA` | `#1E1B18` | `surface` | 设置页、面板的底 |
| 卡片 | `#FFFCF7` | `#292521` | `surfaceContainer` | 一组的底 |
| 按下 / 底槽 | `#EDE7DE` | `#332E28` | `secondaryContainer` | 行按下的高亮、分段控件底槽、胶囊按钮 |
| 分段选中格 `segment` | `#FFFCF7`（卡片） | `#3F3A33` | 浅色 `surfaceContainer`；深色底槽往 `onSurface` 提 8% | 分段控件选中的那一格，比底槽亮一档；上面的字是强调色，不够 4.5:1 时自动调（深色默认是 `#E29667`）。不用深色的 `secondary`：那是开关关着时的浅米色轨道 |
| 文字 | `#292621` | `#E6DDCF` | `onSurface` | 行名 |
| 次要文字 | `#71675C` | `#B9AB99` | `onSurfaceVariantSummary` | 当前值、说明、卡片下小字 |
| 第三级 | `#84786B` | `#9D9081` | `onSurfaceVariantActions` | 箭头、不可用 |
| 组名 | 次要文字 | 次要文字 | `onSurfaceVariantSummary` | 卡片上方的组名 |
| 强调色 | `#A94B36` | `#E0905F` | `primary` | 开关、滑块、选中、链接 |

| 删除 `destructive` | `#C92B5B` | `#F12522` | `error` | 删除、出错；浅色用胭脂红，不用正红 `#E94634`（和朱砂强调色几乎同色）；红底按钮上配白字时把红压深到 4.5:1 |
| 提醒 `warning` | `#A85500`（默认强调色下 `#A15A00`） | `#FF9F0A`（默认琥珀下 `#F9A200`） | — | 该处理了、知识库放不下这类提醒；卡片和页面底上都 ≥ 4.5:1 |
| 成功 `success` | `#15803D` | `#30D158` | — | 完成、通过、定稿；同上 |

语义色在不同的底上会自动调到够对比度（`readableOn`）：Monet 的卡片底、阅读面板的纸白 / 宣黄 / 竹青 / 灰蓝 / 墨夜上都 ≥ 4.5:1，小字读得清。
删除色、提醒色和强调色两两要分得开：调到读得清以后 CIEDE2000 色差 ≥ 15（`SEMANTIC_MIN_DELTA`），不够时只转色相、不动明度（`distinctFrom`），
所以选了红色、橙色强调色或 Monet 生成相近的主色时，删除、提醒会自动换一个分得开的变体；表里括号中的就是默认强调色下转出来的值。
`ThemeContrastTest` 把纸色、各强调色和配色风格的 Monet、阅读面板逐一算过。
不写死 iOS 的系统色（`#FF9500` 在白卡上只有 2.2:1）。

## 各界面

### 阅读页（样稿：“灵阅阅读界面样稿”）

- 读书时屏幕上只有正文：顶上一行小字页眉（章名，跟着书页一起翻；章首页下面就是大字章名，不再写页眉），底下一根全书进度细线（强调色）和一行小字（左边章名；右边“第 N/M 页 · 本章余多久”，全屏时补上时间、电量）；
  两侧书口是两摞纸，只有几像素。
- 章首：序号（“第一章”）小字、强调色、字距拉开；章名大字半粗；下面一道 28dp 的短线。
- 配色：纸白底 `#F5F0E6`、字 `#2B2620`、次要 `#6F665A`、朱砂 `#B5432F`；墨夜底 `#191714`、字 `#D6CDBB`、次要 `#8E8676`、琥珀 `#E0905F`；另有宣黄、竹青、灰蓝。
- 加了书签的页，右上角垂下一条燕尾书签丝带。
- 点中间出菜单，都浮在书页上：
  - 顶上一条胶囊：返回、书名（下面作者 · 已读多少）、书签、书内搜索、更多（自动滚动 / 自动翻页、书籍详情）；
  - 底下一块：‹ 上一章 · 章名 · 下一章 ›、全书进度细线滑块（3dp 轨道、白色圆钮，左“全书 N%”、右“本章 X/Y 页”）、目录 / 听书 / 外观（衬线 Aa）/ 设置四格；
    菜单出来时页脚淡掉，不在底栏下面露半行字；打开目录、外观等面板时菜单收起。
- 选区两端的把手是一道细竖线和一个 7dp 圆点，落在行间空白里，不盖住下一行的字；能按的范围 48dp。
- 选字后的操作条是一颗紧凑深色胶囊（可见高 38dp、触控高 48dp）：查词 | 划线 | 批注 | 复制 | 卡片；点书页别处收起。
- 查词先弹小卡片：词和读音大字，右上角划线、收入生词本（星），下面头几条释义和原句，最底下汉典、百度汉语和“完整释义 ›”；展开后是整页的分组查词面板。
- 目录：从左侧滑出，宽度不超过屏幕的 86% 或 360dp；书名与进度在顶端，分段控件切换目录 / 书签 / 批注；目录可切正序或倒序，点击仍按原始章节编号跳转。当前章用淡强调色标出，点侧栏外关闭。
- 面板的强调色：没在主题设置里挑过强调色、也没开 Monet 时，跟着书页走（朱砂 / 琥珀）。

### 阅读设置（面板）

- 菜单里的“外观”打开首页（标题“外观”，右上角“完成”），一张卡片一件事：
  - 亮度：两头太阳、灰色滑块，右边“自动”；
  - 背景：一排圆形书页配色（纸白、宣黄、竹青、灰蓝、墨夜、自定义）；
  - 文字：“字号”一行（右边小 A、字号、大 A 的步进器），“字体 ›”一行，“排版”一行（右边紧凑 / 标准 / 宽松分段）；
  - 最后“翻页方式 ›”“更多设置 ›”。
- 菜单里的“设置”直接打开“阅读设置”：字体、排版、翻页方式、繁简与注音；点按与按键、护眼、屏幕。
- 二级页：
  - 排版：预设（紧凑 / 标准 / 宽松）、行距、段距、字距、边距、段首空两格、两端对齐、恢复默认；
  - 翻页方式：勾选列表、书页厚度、横屏时双页；
  - 点按与按键：点按翻页、九格点按区域（预设：左右翻页 / 单手）、音量键翻页；
  - 护眼：跟随环境光、系统深色时用夜间背景、日落后逐渐变暖、远眺提醒；
  - 屏幕：全屏、屏幕常亮、方向、墨水屏 / 省电模式；
  - 字体、繁简与注音、自定义配色（选了“自定义”配色时出现）。
- 面板跟着内容高矮，最高到屏幕的 85%，内容多的页在里面滚动；换页时高度渐变过去。返回键先回首页，再关面板。

### 听书（面板）

进度一行、大号的上一句 / 播放 / 下一句；语速滑块；语音、定时关闭两个勾选列表。

### 查词、注释、书摘卡片（面板）

- 查词照苹果的“查询”：标题栏右边“管理词典”；词头大字，两边各一对小圆钮微调选区；
  下面一排三格操作（收入生词本、复制、划线·批注）；字典、词典、导入的词典、相关词语各一组，组下小字注明来源；
  最后一组“在线查询”（汉典、百度汉语、其他词典 App）。
- 注释：标题栏右边“完成”，注释正文用书里的字体放在一张卡片里。
- 书摘卡片：标题栏右边“分享”；预览图带阴影居中，下面是配色的分段控件和“保存图片”。

### 写作

- **作品页**：顶部“作品进度”只汇总字数、章节状态和待整理事项；“继续写 / 新的一章”“设定包”“故事账本”“写作 AI”是日常直达入口。预览、变更登记、伏笔和规则放在可展开的“更多功能”，不挤占手机首屏。总纲、卷、章、细纲卡在同一“规划树”里；卷可折叠，点章打开编辑器，章右侧单独的 48dp 卡片按钮一点直接进这一章的细纲卡页。长按章打开管理菜单；批量调整顺序时显式进入调整模式：“调整章节顺序”是带行首图标、下面一行说明的一行（和总纲同一张卡片），调整中换成强调色“完成调整”并挂“调整中”标签；每章右侧换成一对紧凑的上下箭头（28dp 圆底、能点 48dp，到头的变灰），读屏念“上移第一章 雪夜”，不要求精细拖拽。
- **编辑器**：正文占主要高度，是视觉中心。键盘上方常态保留一行：左侧“AI”“书灵”两个带字图标（`LabeledIconButton`，长按有说明），中间一项智能推荐，右侧“工具”入口。推荐根据空章、选区、修订、节拍、定稿和 AI 配置等状态改变，只导航到现有安全流程（“写第 N 拍”点了直接写，结果照样要在面板里采纳）；在光标处写正文只有“AI 写”一个对话框（节拍、写多少、3 个方向、照范本写法，见上面“对话框里选一项”）；书灵面板只放问主意（一排换行的淡色胶囊）和范本两节。生成中或有待处理结果时只显示状态。推荐用淡强调色底、强调色字（✦ 名字，下面一行灰色理由），不铺整条实心色；还没设置写作 AI 时只是一枚描边的“设置写作 AI”次要按钮，不带副标题。点工具入口后，贴着键盘展开写作工具：没有单独的标题栏，“写 / 查 / 整理 / 更多”是铺满一行的分段控件，关闭钮在它右端；下面是一格格等宽的工具（`ToolTileGrid`），宽屏五格也排一行，窄屏每行四格换行，每个工具一个分得开的图标。整个面板约两行高，360 × 640 的小屏上正文仍露出大半屏。“全部工具”能打开完整旧菜单。快捷标点条与原 AI 工具条可切换回来，键盘展开时不另铺一整屏常驻工具。
- **三道审稿**：章名和上次审稿一张卡片，下面整宽的主按钮“开始审稿 / 重新审稿”（审着时是红色“停止”）；还没审过时“依次审三关”一张卡片，三关各一行（标题一行、说明一行），审过后每关一组列结果。
- **AI 正文候选稿**：“AI 写整章草稿”按“你的构思 → 开始创作 / 继续处理 → AI 拟写法 → AI 正文草稿 → 本稿审读 → 你来审定”组织。构思和目标篇幅由作者填写；范本写法图与原文范围按需展开。候选正文、审读证据、来源和实际用量在采纳前可查看。只有作者点“放进正文”且审读与范本来源核验满足当前流程要求时才进入正文；放进正文后仍待作者定稿。编辑器内的续写结果也只在结果面板采纳或撤回，推荐按钮不能代替这一步。
- **故事账本**：按“人物 / 伏笔 / 知情 / 全部记录”切换同一份账本，这条分段控件左右和卡片一样缩进 12dp。
  人物卡的状态方面胶囊放不下就换行；知情格一人一格，人多时左右滑、边缘渐隐（`FadingScrollRow`）。
  章号（从第几章起、到第几章止、计划第几章收、第几章收的、从第几章生效 / 得知）都用步进器，空着是“不填”。
  “看到第几章”对话框打开时滚到选中的那章；章多时上方一条“快速定位”滑条，拖到第几章列表就滚过去，点了那一行才算选上。人物卡按状态方面就地打开登记对话框；伏笔卡以章号滑块调整计划收章；知情格显示已知、尚未知或较晚才知，点格子核对来源或填写获知章与消息来源。选章和人物后只看对应进度，旧章状态不被新的状态覆盖。图形修改后提供“撤销上一步”；若该条已有后续修改，拒绝覆盖并引导查看历史版本。账本与设定包分开，导入、导出仍通过显式入口完成。
- **触控与动效**：章节卡片按钮、排序按钮、编辑器工具按钮及图形操作至少 48dp 可点；图标操作提供文字标签或无障碍描述。规划树的增删与排序使用 `Motion.listItem()`，编辑器工具浮层使用 `InlinePanel` 的底边进出，账本换筛选用 `Motion.fadeThrough()`；减少动效时直接换状态，保持浅色、夜间和墨水屏可读。

### 生词本

大标题；学习中 / 已掌握分段控件铺满一行（左右和词卡一样缩进 12dp）；有到期的词时，下面一张卡片一行“复习 N”（行首图标、下面一行说明，点进去翻卡片），没有到期的写一行灰色小字“下次复习：…”。每个词一张卡片：词和读音，右上角两个小图标（标为掌握、删除）；
释义（导入词典的条目先去掉目录、部首笔画这类，取带义项编号的头两条）；书里的原句左边一道竖线；最后一行灰色小字写《书名》、日期、下次复习。

### 我的

大标题；阅读（词典、主题设置）；备份（备份书架、从备份恢复、自动备份到文件夹，开着时再有备份位置、现在备份一次）；关于（版本、项目主页）。行首使用低饱和图标。

### 主题设置

照“显示与亮度”：三部小手机选外观（跟随系统 / 浅色 / 深色）；强调色圆点（一行，放不下左右滑，选中的打勾）、Monet 取色、配色风格；
效果（模糊、液态玻璃、悬浮底栏）；墨水屏；页面切换动画和界面缩放（名字和百分比一行，滑块一行）。每个开关的作用写在它自己下面。

### 词典

内置词典一个开关；导入的词典一行一本带开关；右上角“编辑”进入编辑状态，每行出现红色删除和上下移动。

### 书籍详情

左边封面、右边书名作者（格式 · 章数 · 字数，读到哪）；下面整宽的“开始 / 继续阅读”，和卡片左右对齐；简介；信息（累计阅读、添加于、最近阅读、来源文件）；操作；最后单独一组红色的“移除”。

### 书架

大标题“书架”，右上角搜索、导入、排序；一行三本。生成的封面是布面色块：左边一道书脊，上方衬线书名和一道短线，下方作者。
封面下面书名（两行）、进度小字，右边一个小“⋯”（看着 18dp，能点 48dp，列表样式里的也一样）；长按封面也能出菜单。

### 统计

大标题“统计”；今天写大，本周 / 本月 / 今年并排小一号；每日目标（进度、“每天读”菜单选择、晚上提醒开关）；近 20 周热力图；各本书的时长。
