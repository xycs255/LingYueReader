# 灵阅界面规范：选项与设置

所有“选项”界面——阅读页的设置和听书面板、“我的”、主题设置、词典、书籍详情、统计里的目标——都照苹果“设置”和 Apple Books 的做法来做。
组件都在 `app/src/main/java/com/xycs/lingyuereader/ui/Grouped.kt`，新加的选项从那里取，不要另写一套。动效取值见 `docs/motion.md`。

## 原则

1. **一行一件事**：每行只写一个短名字（两到六个字），当前值放在右边灰字里。解释、注意事项写在这一组下面的小字里，不挤在行里。
2. **分组**：相关的几项放进一张圆角卡片，组与组之间留白；组名是卡片上方的灰色小字，可以没有。
3. **常用的放外面，其余点进去**：一屏放得下最常调的几样，其余按用途分成二级页，从带“›”的行点进去，左上角“‹ 返回”。
4. **控件各司其职**：
   - 开 / 关 → 开关（打开是绿色）；
   - 二到五个互斥的短选项 → 分段控件；
   - 选项多、或需要说明 → 勾选列表（单独一组或一页）；
   - 选项不多、不想占地方 → 菜单式选择（右边灰字加小箭头，点开弹出菜单）；
   - 连续的数值 → 滑块，两端放小图标或小字说明方向；
   - 动作 → 强调色文字的一行；会删东西的用红色，单独成组放在最后。
5. **深浅色两套**：配色取苹果的系统色，深色下的面板比页面亮一级。强调色跟随“主题设置”里选的颜色。

## 各界面

### 阅读页（样稿：“灵阅阅读界面样稿”）

- 读书时屏幕上只有正文：顶上一行小字页眉（章名，跟着书页一起翻），底下一根全书进度细线（强调色）和一行小字（章名；页码与本章还剩多久，全屏时补上时间、电量）；
  两侧书口是两摞纸，只有几像素。
- 章首：序号（“第一章”）小字、强调色、字距拉开；章名大字半粗；下面一道 28dp 的短线。
- 配色：纸白底 `#F5F0E6`、字 `#2B2620`、次要 `#6F665A`、朱砂 `#B5432F`；墨夜底 `#191714`、字 `#D6CDBB`、次要 `#8E8676`、琥珀 `#E0905F`；另有宣黄、竹青、灰蓝。
- 加了书签的页，右上角垂下一条燕尾书签丝带。
- 点中间出菜单，都浮在书页上：
  - 顶上一条胶囊：返回、书名（下面作者 · 已读多少）、书签、书内搜索、更多（自动滚动 / 自动翻页、书籍详情）；
  - 底下一块：‹ 上一章 · 章名 · 下一章 ›、全书进度滑块（左“全书 N%”、右“本章 X/Y 页”）、目录 / 听书 / 外观（衬线 Aa）/ 设置四格。
- 选字后的操作条是一颗深色胶囊（墨色底、纸色字）：查词 | 划线 | 批注 | 复制 | 卡片；“划线”直接用黄色划上，“批注”打开面板，点书页别处收起。
- 查词先弹小卡片：词和读音大字，右上角划线、收入生词本（星），下面头几条释义和原句，最底下汉典、百度汉语和“完整释义 ›”；展开后是整页的分组查词面板。
- 目录：小书封、书名、作者 · 已读 · 还剩约多久，右上角关闭；分段控件切换目录 / 书签 / 批注；每章一行：序号、宋体章名、右边要读多久，正在读的那章铺一层淡强调色，写“正在读 · N%”。
- 面板的强调色：没在主题设置里挑过强调色、也没开 Monet 时，跟着书页走（朱砂 / 琥珀）。

### 阅读设置（面板）

照 Apple Books 的“主题与设置”：

- 菜单里的“外观”打开首页（标题“外观”，右上角“完成”）：字号卡片（小 A · 永 19 · 大 A）、亮度（两头太阳，墨色滑块，右边“自动”）、
  一排圆形书页配色（纸白、宣黄、竹青、灰蓝、墨夜、自定义）、字体分段（宋体 / 黑体 / 导入的）、排版预设分段（紧凑 / 标准 / 宽松），
  最后“翻页方式 ›”“更多设置 ›”。
- 菜单里的“设置”直接打开“阅读设置”：字体、排版、翻页方式、繁简与注音；点按与按键、护眼、屏幕。
- 二级页：
  - 排版：预设（紧凑 / 标准 / 宽松）、行距、段距、字距、边距、段首空两格、两端对齐、恢复默认；
  - 翻页方式：勾选列表、书页厚度、横屏时双页；
  - 点按与按键：点按翻页、九格点按区域（预设：左右翻页 / 单手）、音量键翻页；
  - 护眼：跟随环境光、系统深色时用夜间背景、日落后逐渐变暖、远眺提醒；
  - 屏幕：全屏、屏幕常亮、方向、墨水屏 / 省电模式；
  - 字体、繁简与注音、自定义配色（选了“自定义”配色时出现）。
- 面板固定为屏幕高度的 78%，换页时不忽高忽低；返回键先回首页，再关面板。

### 听书（面板）

进度一行、大号的上一句 / 播放 / 下一句；语速滑块；语音、定时关闭两个勾选列表。

### 查词、注释、书摘卡片（面板）

- 查词照苹果的“查询”：标题栏右边“管理词典”；词头大字，两边各一对小圆钮微调选区；
  下面一排三格操作（收入生词本、复制、划线·批注）；字典、词典、导入的词典、相关词语各一组，组下小字注明来源；
  最后一组“在线查询”（汉典、百度汉语、其他词典 App）。
- 注释：标题栏右边“完成”，注释正文用书里的字体放在一张卡片里。
- 书摘卡片：标题栏右边“分享”；预览图带阴影居中，下面是配色的分段控件和“保存图片”。

### 我的

大标题；顶上一张灵阅名片；入口组（词典、主题设置，带彩色图标）；数据组（自动备份、备份位置、现在备份一次、备份书架、从备份恢复）；关于。

### 主题设置

照“显示与亮度”：三部小手机选外观（跟随系统 / 浅色 / 深色）；强调色圆点、Monet 取色、配色风格；效果（模糊、液态玻璃、悬浮底栏）；墨水屏；页面切换动画和界面缩放。

### 词典

内置词典一个开关；导入的词典一行一本带开关；右上角“编辑”进入编辑状态，每行出现红色删除和上下移动。

### 书籍详情

照 Apple Books：居中大封面、书名作者、整宽的“继续阅读”；简介；信息（篇幅、累计阅读、添加于、最近阅读、来源文件）；操作；最后单独一组红色的“移除”。

### 统计

大标题；今天 / 本周 / 本月 / 今年；每日目标（进度、“每天读”菜单选择、晚上提醒开关）；近 20 周热力图；各本书的时长。
