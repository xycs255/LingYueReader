# 灵阅 LingYue Reader

一个开源、无广告的 Android 阅读器，专注中文长篇阅读。默认不联网；可选的书源（OPDS、WebDAV）和 AI 助手只连你自己设置的地址。

## 功能

- **多种格式**：TXT（自动识别 UTF-8 / GBK 编码与“第X章”“楔子”“番外”等章节）、EPUB（按书脊与目录分章，
  显示插图，书架上用书的封面；注释角标显示为小号上标，点一下弹出注释，不用跳到书末）、Markdown（标题、引用、列表、表格都能排版）、
  Kindle 的 MOBI / AZW3（无 DRM；按目录或分页符分章，带插图和封面）、FB2（含注释、诗歌、插图）。
- **PDF 和漫画**：PDF 按页显示（系统自带的 PdfRenderer 现画，不另存一份），CBZ 漫画直接从压缩包里读图，
  分了文件夹的按文件夹分章，否则每 20 页一章；长按一页打开大图，双指缩放、双击放大。这两种书没有文字，不能选字和听书。
- **大部头也快**：导入时解析一次并写缓存，之后打开只读目录，章节读到才加载。
- **合集导入**：一次选多个文件可以合成一本书。文件按名字自然排序（第2卷在第10卷前）；
  若每章都有“第X章”序号，就按章号排序，同一章以后面的文件为准——适合作者分批修订的文稿。
- **净化与分章规则**（TXT / Markdown，书籍详情 → 净化与分章规则）：用文字或正则批量删掉、替换广告和水印行；
  自动分章不对时选一个常见格式（【章名】、数字序号、Chapter N 等）或自己写正则；改动实时预览分出几章、每条规则
  匹配几处，保存后重新整理。规则只影响显示，不改原文件，备份时一起打包。
- **从原文件刷新**：记住每份文件的来源（手机存储、Google 云盘等），原文件改过后长按书籍即可刷新。
- **注音**（阅读设置 → 注音）：在每个汉字上方标拼音，适合孩子和学中文的人。多音字按词定音——先在内置词典里找从这个字开始
  最长的词（“银行”的“行”读 háng、“行长”的“长”读 zhǎng），找不到再取这个字最常用的读音；行距随之加高，分页一致。
- **仿真翻页**：像翻纸书一样掀起书页一角。在下三分之一按住掀右下角、上三分之一掀右上角，角跟着手指上下走；在中间按住整页竖着卷过去；点按、音量键翻页从右下角掀。
  Android 13 起书页是绕着圆柱卷起来的（正面渐暗、背面隐约透出反字、下一页上落一道阴影），更早的系统是平折；
  翻起的背面隐约透出反着的字，折痕处有阴影。往回拖就把那页放回去。
- **横屏双页**：平板或手机横过来、屏幕够宽时，左右并排两页，像摊开的书，两页一起翻（阅读设置里可关）。
- **竖排**（阅读设置 → 翻页方式 → 竖排）：字从上往下、列从右往左，像古书那样读，页也从右往左翻（点左边是下一页）。
  标点换成竖排字形（︒︐﹁﹂︽︾），句号逗号不出现在列首；英文横躺着排，一两位数字横着并排放在一格里（纵中横）；
  长按查词、划线、听书高亮照常；插图单独占一页。
- **繁简转换**：阅读设置里选“繁转简”或“简转繁”，按 OpenCC 词组优先转换（“头发”→“頭髮”，“皇后”不会变成“皇後”），
  转换不改变字数，书签批注位置不受影响；读到哪章才转换哪章。
- **中文排版**：严格避头尾（句号、逗号、后引号不出现在行首），相邻全角标点挤压（字体支持时），中文书的弯引号、省略号
  按中文字体排成全角（不受系统语言影响）；两端对齐时，避头尾挪字后行尾空出的一点宽度会均匀摊到字间，每行右边严格对齐；段首空两格、两端对齐都可开关，翻页模式分页随之一致。
- **自定义字体**：阅读设置里“＋ 导入字体”，支持 TTF / OTF / TTC（如霞鹜文楷、思源宋体），分页与选区按所选字体计算；
  长按导入的字体可删除。字体文件较大，不随备份打包，恢复后找不到字体时自动用回宋体。
- **粗体文本**（阅读设置 → 字体，照 Apple Books）：正文加粗到半粗，笔画细的字体、调暗屏幕时更好认；滚动、翻页、竖排都一样。
- **阅读体验**：上下滚动或左右翻页（平移 / 覆盖 / 仿真 / 无动画），点两侧或按音量键翻页，跨章节连续翻；
  宋体/黑体、字号、行距、段距、亮度可调；纸白、宣黄、护眼、夜间四种背景，系统深色时可自动切夜间；
  可隐藏状态栏全屏阅读；菜单里有全书进度条，拖动即跳转；自动记住每本书读到哪里；书内全文搜索。
- **按研究定的阅读细节**（依据见 [docs/reading-research.md](docs/reading-research.md)）：点按 / 音量键翻页统一 300 毫秒动画；
  滚动模式点一下按能看清的那段翻、刚读完的一行留在顶上，并在原来的底边划一道短线标出接着读的地方；跳到书签、批注、搜索结果时，落点那段亮一下再褪掉；
  状态行顶上一根全书进度细线；翻页模式下书页夹在两摞纸中间（“书页厚度”）：左边读过、右边没读，书越长越厚，纸边是一张张细线、两头圆过去，书页压在上面投下阴影；
  拖着翻页时一页纸跟着手指从一摞换到另一摞，翻起的纸在两摞上投影（仿真最深，覆盖、平移淡些，无动画没有），平移、覆盖、仿真的书页都只在两摞之间动；一键排版（紧凑 / 标准 / 宽松）；
  系统关了动画时灵阅也不做动效。
- **动效**：书从封面放大打开、退出时缩回封面（读过的书排到最前也能找对位置）；页面层级滑动；换主题从手指点的地方圆形扩散；
  书架和生词本的增删换位平滑挪动；复习卡翻面、换卡滑动；统计数字从 0 数起、热力图逐列亮起；长按选词、捏合调字号有轻震。
  墨水屏 / 省电模式下全部关闭。规范见 [docs/motion.md](docs/motion.md)。
- **主题设置**（我的 → 主题设置）：跟随系统 / 浅色 / 深色；Monet 取色（Android 12 起从壁纸取色）或选一种强调色生成整套配色，
  可选配色风格；模糊、液态玻璃、悬浮底栏各自可关；页面切换动画（层级滑动、淡入淡出、无）；界面缩放 85%–115%。
- **HyperOS（miuix）风格的选项界面**：阅读设置、听书、目录、划线面板和“我的”、主题设置、词典、书籍详情、统计、净化与分章，
  都是 HyperOS 设置页式的白卡片分组——卡片上方蓝灰组名、一行一个短名字、当前值在右边灰字、解释写在卡片下面；
  开关、滑块、下拉选择用 miuix 的控件，配色跟着 miuix 主题（深浅色、Monet、强调色）。
  阅读页照“灵阅阅读界面样稿”：读书时只有正文、一行页眉、一根进度细线和一行页脚；章首序号朱砂小字、章名大字、一道短线；
  菜单浮在书页上（书名 · 已读、上一章 / 下一章、全书进度、目录 / 听书 / 外观 / 设置）；选字后是深色胶囊操作条，查词先弹小卡片。
  “外观”是字号、亮度、书页配色（纸白、宣黄、竹青、灰蓝、墨夜、自定义）、字体和排版预设；“设置”是其余各项，按字体、排版、翻页方式、点按与按键、护眼、屏幕分页点进去。
  规范见 [docs/design.md](docs/design.md)。
  顶上的小手机预览随设置即时变化。墨水屏 / 省电模式也在这里。
- **随手调**：字距、边距可调；背景除了四种预设还能自定义底色和字色（显示对比度，太低会提醒）；
  双指捏合正文直接调字号；正文分成九格，每格可设上一页、下一页、菜单或不响应（有“单手”预设）；
  阅读时可锁定竖屏或横屏。
- **回到刚才**：从目录、书签批注、进度条、书内搜索跳走后，页底出现“↩ 回到刚才”，一点就回到跳转前读的地方。
- **自由划选**：长按正文不松手接着拖，就能划选一段文字，按整词伸缩，可以跨段落；滚动模式下拖到屏幕上下边缘会自动滚动。
  松手后两端有把手可以微调（也能拖到别的段落）：往外拉按词对齐，往回收按单字走。操作条上可查词（限一段之内）、
  划线·批注（跨段时每段一条划线）、复制。手感参照 Android 系统文本框和 Compose 的选字：放大镜锁在正在选的那一行，
  手指停在两行交界处不会来回跳，每走一格轻震一下，抬手时指腹一滚多出的那一个字会撤回。
- **书摘卡片**：划选后点“卡片”，把句子排成一张图片（书名、作者、章节，纸白 / 宣黄 / 竹青 / 墨夜四种配色，
  用你选的阅读字体），可以直接分享，或保存成 PNG（系统“另存为”，不需要存储权限）。
- **自动滚动**：阅读菜单顶栏的“▶”开始。滚动模式按“每分钟几行”匀速滚，翻页模式按同样的速度定时翻页；
  默认速度按你的阅读速度估算，控制条上可暂停、加减速、停止，点正文也能暂停；打开菜单、面板或划选时自动暂停，
  章末接着下一章。
- **字典与词典**：长按正文里的字直接松手，自动选出它所在的词（可左右调整选区）并查词：
  - 内置离线的基础字典（Unihan：读音、部首、笔画、繁简）和词典（CC-CEDICT：拼音、英文释义、相关词语）；
  - 导入 MDict 词典（`.mdx`，连同 `.mdd` 图片资源和 `.css` 样式一起选），查词时依次列出各本词典的释义，
    可在“我的 → 词典”里启用、排序、删除；
  - 一键到汉典、百度汉语在线查询（打开浏览器），或交给手机上已装的其他词典、翻译应用。
- **生词本**：查词面板里一点“☆ 收入生词本”，连同读音、释义摘要和书里的原句一起收下；
  生词本（底部导航“生词本”）分“学习中/已掌握”，可以导出 Markdown，备份时一起打包。
  复习按遗忘曲线安排：只出到期的词，记得就隔 1 天、3 天、约 8 天……越来越久，没记住的从头来、这一轮最后再出现一次；
  间隔超过两个月算掌握。每个词卡片上写着下次复习的日子。
- **阅读统计**：按天记录阅读时长和读过的字数（跳章、拖进度条不算），统计页（底部导航“统计”）显示今天、本周、
  本月、今年的时长，连续阅读天数，近 20 周热力图和各本书的时长；阅读页底部按你自己的阅读速度估算“本章约剩几分钟”。
- **每日目标**（统计页）：设每天读 15–90 分钟，显示今天读到哪了；可以让它晚上 9 点看一眼——还没读够就发一条通知，
  连续读了好几天、今天还没读的，提醒别断了（不精确闹钟，省电；开机后自动重新排上）。
- **护眼**：背景不做花哨的动画，而是跟着环境走（依据见下文“护眼的依据”）：
  - 跟随环境光：有光线传感器时，昏暗处自动压暗背景，很暗时换夜间，减少屏幕与周围的亮度落差；读数按时间平滑、
    换档要持续数秒且两次换档至少相隔 30 秒，不会来回闪；设置里能看到当前读数；关灯读太久会提醒开灯；
  - 日落后逐渐变暖，颜色变化都会缓慢过渡；
  - 远眺提醒（20-20-20）：每连续阅读 20 分钟，画面淡出成一幅远景，请你看向远处 20 秒，可跳过或推迟 5 分钟；听书时不打断；
  - 配色：日间不用纯白底，夜间用偏暖的浅黄字和琥珀色强调色，所有组合对比度不低于 7:1。
- **墨水屏 / 省电模式**（“我的”或阅读设置里打开）：关掉玻璃、动画和环境光变色，书页纯白底黑字（选夜间则黑底白字），
  菜单换成描边的纯色块，翻页、换页不带动画；适合墨水屏阅读器，旧手机上也省电。
- **AI 助手**（可选，默认关闭；“我的 → AI 助手”里开启）：用你自己的服务商和密钥，内置 DeepSeek、通义千问、Kimi、
  智谱 GLM、Claude 的地址和模型名，也可以接家里电脑上的 Ollama、LM Studio（局域网地址可用 http://、不填密钥），
  或任何兼容 OpenAI / Anthropic 接口的服务；填好后可“测试连接”。设置里还能改回答长短、改或加划选后的快捷问题。
  也可以选“本机模型（离线）”：在手机上跑 Qwen2.5（Apache-2.0 许可）的 1.5B 或 0.5B 模型，不联网也不花钱（下载模型时除外，可断点续传、核对校验和），
  也能从文件导入 .task 格式的模型；要 64 位手机，1.5B 建议 8 GB 内存以上。本机模型比联网的大模型慢、写得差一些，上下文也短，写作 AI 会只带一小段设定资料。开启后：
  - **问 AI**：划选后操作条上多一个“问 AI”，点快捷问题（默认“解释”“翻译”“背景”）或自己打字问；选中的文字连同所在段落一起发出，
    回答边生成边显示，可以接着追问；回答可以“存为批注”；
  - **AI 释义**：查词卡片上的“AI 释义”，按书里的原句给出读音和中文解释（内置词典只有英文释义）；
  - 阅读页顶栏的 ✦ 按钮里：
    - **本章伴读**：本章要点和三道思考题，点一道题和 AI 讨论时只引用当前阅读位置之前的正文；滚动模式章末也有入口；
    - **AI 讲书**：把这一章或读过的部分讲成一段约 1500 字的讲书稿——一人讲解，或主讲和搭档两人对谈的播客，
      再一句句读出来（设了 AI 朗读就用 AI 语音，两人各用一个声音；否则用系统语音），正在读的句子高亮，点哪句从哪句读；
    - **前情提要**：把停下处往前约一万六千字发出，写成几条要点和“你停在哪里”；只在上次提要未越过当前阅读位置时复用，也可以“重新生成”；
    - **问这本书**：只在读过的部分里找相关原文——先让模型把问题改写成检索词（补别称、把追问里的“他”换成具体的人），
      按关键词（BM25）找；设了向量模型时，每次最多将关键词排名前 30 段及最近 10 段发送给向量服务（至多 4 批正文和 1 次问题请求），再融合排序。回答标出引用 [1][2]，点出处跳到原文；
    - **人物表**：从书开头（或上次整理到的地方）到读到的地方，分段整理出场人物的身份、经历和关系，存在本机，
      读到新内容点“更新”只补新的部分；长按正文里的人名，查词面板顶上直接显示人物卡；
    - **读书笔记**：把这本书的划线和批注整理成一篇笔记（每章要点、摘句、你的想法、总结），可复制、分享、存成 .md；
    - **翻译本章**：整章分批译成中文、白话（文言译白话）或英文，译文接在每段原文下面（小一号、淡一些），
      存在本机，可隐藏、可删；书签批注、进度和听书都只按原文；
    - **对话记录**：问 AI、问这本书的对话按书保存（最近 50 段），可以接着问；
  - **章节速读**：目录里每章一段 60 字以内的摘要，可选读过的、接下来 10 章或全书（先显示约多少字）；
  - **AI 朗读**（设置里单独配置）：听书换成服务商的语音——内置硅基流动 CosyVoice、OpenAI、局域网 Kokoro，
    或任何兼容 OpenAI `/audio/speech` 的服务；可选声音、试听，听书面板里随时切回系统语音；
    边读边预取后面几句，读过的句子缓存在本机，重听、往回跳不再花钱；
  - 生词本：每个词可以要“AI 例句”（例句、用法、近义词辨析，复习卡背面也显示）；没有释义的词一键“AI 补释义”。
  
  没读到的内容不会发出去，提示词也要求不剧透。
- **离线语音**（我的 → 离线语音）：听书和 AI 讲书可以用手机上的 AI 语音模型合成，不联网、不花钱，
  比系统语音自然。引擎是 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)，打包在应用里；模型不打包，读者选一个下载（只需一次）：
  Kokoro 中英（下载 147 MB，女声、男声各 8 个，最自然，合成较慢，适合较新的手机）或 MeloTTS 中英（下载 167 MB，一个女声，合成快）。
  下载中断了下次接着下，下完核对 SHA-256；下载不了时可以用电脑从 sherpa-onnx 的发布页下好 `.tar.bz2` 再“从文件导入”。
  听书面板里在系统语音、离线语音、AI 语音之间切换；模型闲置几分钟后自动释放内存。
  只收许可证允许随意使用的模型：训练数据仅限非商业使用（如标贝）或来源不明的中文模型没有收。
- **写作**（底部导航“写作”）：给长篇作者用的写作工具，不联网，稿子只存在本机。
  - **作品、卷、章**：一部作品按卷分章（只有一卷时就是“正文”）；长按章节改名、改状态、写细纲卡、上移下移（可以挪到相邻的卷）、删除，点卷名改卷名或删卷。
  - **章节状态**：细纲 → 草稿 → 修订 → 定稿，章节列表上标着颜色，作品页统计各状态多少章；细纲章写了字自动变草稿。
    **定稿后正文锁定**（编辑器只读，AI 也改不了），要改先写下原因解锁，记进**变更登记**；改动涉及设定（人数、生死、谁知道什么）时选“涉及设定”，
    登记里会一直标“待同步”，直到你把设定包改好、标为已同步。定稿时存一个历史版本；“已定正文”文件导进来就是定稿。
  - **细纲卡**：每章一张，只划事实边界——本章事实与结果、后文承接边界、视角人物、倒计时、章末钩子、推进的线；页面上列出上一章留下的钩子和承接边界。
  - **细纲卡自动提取**：没写过细纲卡的章，自动从设定包里写到这一章的段落提取（卷纲细纲在前，接续索引、总纲里写到的标“另见”接在后面）——
    认“### 第十九章 章名”这样的标题、“- **第十九章 章名**：……；钩子：……”和“- 第1章《章名》：……”这样的列表项、表头有“事实”“钩子”“边界”这类栏目的表格、
    “第十九至二十一章”这样的章组；“第12、14、40章”这样一条写好几章的算互相参照，不当哪一章的细纲；上下章（“渡口（上）”“渡口（下）”）分开认；
    后面补记、修订里再写到同一章的接在后面；按章名找（章号顺延也对得上），找不到再按章号（按卷编号的挑同一卷）；
    “钩子：”“边界：”“视角：”“倒计时”“××线：”归到对应的项，“某某视角”认作视角人物，其余是本章事实。细纲文档改了，没动过的卡跟着变；在卡上改过以后按你改的，细纲里不一样时可以一键换回。
    写作 AI 改这一章、给灵感、查矛盾时会带上它。
  - **AI 拟细纲**（细纲卡页）：细纲里还没写到的章（往后要写的），让 AI 按本章资料（总纲里这一卷的速查、前几章的细纲或摘要、人物、察觉、伏笔）、
    上一章结尾和下一章已经定下的细纲拟一张细纲卡，看过再用。
  - **检查规则**（作品页 → 检查规则）：把写作规范里数得出来的硬规则写成设定包里的“检查规则”文档，每行一条——
    “字数：3000-6000”（“汉字：…”只数汉字）、“至多 1：点了点头、顿了顿／一顿”、“合计至多 1：没说话、没吭声”、“至少 1：…”、“禁用：您”、
    “句式：不是……而是……”（“……”是一句之内的几个字，“某人”是一个称呼）、“短段：12 字以内至多 5 处”、“对白占比：20%-40%”；
    词后加“（除外：…）”的说法不算，规则前加“对白”或“叙述”只查引号里面或外面。规则页逐条用白话列出读懂的规则，没看懂的行标红。
    编辑器“更多 → 规则检查”列出本章的统计（字数、对白占比、段落中位长度、平均句长）和不合规则的地方，点一条依次选中正文里出现的位置，
    顶上显示还有几条不合；定稿时也提醒一句（不拦着）。规则页能一键检查全书。这些都在本机算，不联网。
    也可以让 AI 从写作规范、称谓与语气文档里整理一份规则，看过、改过再存。
  - **设定包给 AI 用**（照在 Claude 项目里的用法）：联网的服务商（DeepSeek、通义千问、Kimi、智谱、Claude 等）每次请求时——
    “使用说明”“提示词”这类工作说明放在最前面，AI 照它办事；标了“常用”的文档（知识库）整份放进去，不截、不挑；
    模型上下文放不下时，从最大的一份起改成按需查（DeepSeek 等约 10 万字，作品的 AI 设置里能改）；其余文档只给目录（文档名和各小节），
    AI 用工具自己读（某份文档或其中一节）、按关键词搜设定包和已写正文、读某一章全文。工作说明和知识库每次都一样，服务商按相同开头缓存，后面几次便宜很多。
    随请求带上这一章的提示：设定包里写这一章的原文、出场人物、前情、伏笔、还不该知道的事、已写的章目录。
    写本章、AI 拟细纲、改稿、灵感、查矛盾、事实关都走这一套；AI 正在查什么显示在面板上，“发给 AI 的内容”里列出它查了什么。
    服务商不支持工具调用时自动去掉工具重发；本机模型上下文小、不能用工具，仍按章挑着带（下一条）。
  - **本章资料**（编辑器“更多 → 本章资料”）：请 AI 改稿、给灵感、查矛盾、审稿时，按这一章挑设定，不再整份整份地塞——
    短的常用文档照带；长的（几万字的总纲、人物档案、接续索引）切成小块（带上“第一卷《……》”这样的粗体小标题），按块打分：
    单独写到这一章的最算数，写到一小段范围的次之，“第一至四十章”这样的大范围不算；写到出场人物的、和细纲卡用词相近的加分；
    隔了一卷以上的后文不带，只写后面几章的少算。前几章没写摘要的，用它们的细纲当前情。人物档案只带这一章出场的人（从表格的“人物”列、“- **林月（原创）：**”这样的列表项、只写名字的小标题里认人，
    “字”“小名”也算）；察觉表按“第几章”“第几卷”分成到这一章为止已经知道的、还不该知道的（提醒 AI 别让人物提前知道）；
    伏笔表里没回收的伏笔、计划这一章回收的伏笔；其他按需的文档里提到这一章或出场人物的小节。不用改原来的写法，散文、列表、表格都认。
  - **伏笔**（作品页 → 伏笔）：设定包新增“伏笔表”，列出该回收了（计划回收的章已经写到）、还没回收、已回收的伏笔，点一条标为已回收（改伏笔表那一行）；
    写到计划回收的那一章，编辑器下方会提醒。
  - **三道审稿**（编辑器“更多 → 三道审稿”）：照“先核事实、再审写法、最后对照规则”的次序——事实关请 AI 对照本章资料、细纲卡和上一章结尾，
    挑事实、因果、视角、承接、人物提前知道的问题；写法关只按设定包里的写作规范、称谓与语气审，不用 AI 自己的口味；规则关用本机的检查规则。
    点一处问题回到编辑器、选中原文那一句；结果存在本机，正文改过会提示结果可能过时。AI 的回答不是要求的格式时如实报“出错”，不会当成没问题。
  - **防剧透**：人物档案表格里“结局”“下场”“怎么变”“记忆止于”这类格子、写到后面章节的句子，察觉表里“××这一面”“真相”这类视角人物不知道的格子，
    不放进人物卡和“已经知道的”，另列为“只有作者知道的”，明确告诉 AI 不能写进正文、不能让视角人物知道、旁白也不能说破。
  - **章节摘要**：细纲卡里“写完以后”一栏写本章摘要，可以让 AI 概括正文再改，也可以在作品页“更多 → 补写章节摘要”一次补齐；
    写后面的章时，最近 5 章和更早写到出场人物的章的摘要当前情带给 AI，它就知道前面写了什么。
  - **AI 在编辑器里接着写**（键盘上方 ✦ → “AI 接着写”，或“更多 → AI 写本章”）：从光标处往下写，可选写下一场、写到本章结尾、写 500 字左右或按要求写；
    带着设定包、细纲卡、前情摘要、光标前后的正文（开头不够长时加上一章结尾）、写作规范和检查规则，AI 需要时自己查设定包和前面的章。
    写的字直接以浅色显示在光标处，边写边出；写的时候正文先锁住，可以停止；写完点“采纳”才放进正文（原来的正文先存一个历史版本），
    “重写”再来一版，“撤回”什么都不留。AI 写的字不算码字数；定稿的章不能让 AI 写。
  - **AI 写一版草稿**（编辑器“更多 → AI 写一版草稿”）：整章写一版，篇幅按检查规则里的字数，可以写一句这次的要求（如“多写对白”）。
    写完存成草稿，按检查规则查一遍；能接着写、重写；看过再放进正文（替换或接在后面）。
  - **细纲章号**：大场面拆成上下章、发布章号顺延时，在细纲卡里填细纲章号，察觉表、伏笔、前情里的“第几章”就按它算。
  - **称呼也认得**：人物档案或称谓与语气文档里写“称呼：老韩、韩兄”，或者表格里有“称呼”“别名”一列，正文里只写称呼也认得出是谁。
  - **审稿意见逐条处理**：点一条问题可以“去原文”“按这条让 AI 改”（选中那句，按意见改，先看对比再采纳）、标“已改”或“不改”；
    重新审稿时，标过“不改”的还是不改，审稿途中标的也不会丢。
  - **写作规范太长时节选**：写法关和 AI 写本章最多带 1.2 万字的规范，优先写到出场人物的小节和规范后面新补的小节。
  - **学没采纳的改法**：AI 改稿没采纳的，记下最近 10 条，下次告诉 AI 别这样改。
  - **AI 记录与发送内容**（作品页 → 写作 AI）：灵感、读者点评、矛盾检查、AI 写的章都记下来（最近 100 条），可以复制、删除、标“有用”“没用”；
    “最近一次发给 AI 的内容”能看到发出去的系统提示、设定资料和要求原文，审稿页、写本章页也能看。本章资料带多少字可以调（6 千到 3.2 万字）。
  - **编辑器**：一行就是一段，显示时每段首行空两格（存下的正文不带缩进）；顶上是章名、本章字数和保存状态，可撤销、重做；
    键盘上方一排常用中文标点，成对的引号插进去光标停在中间，选中文字时把它包起来。
  - **不丢稿**：停笔不到一秒自动保存，切到后台、离开这一章时也存；写盘先写临时文件再改名，断电不会写坏。
    每次打开、离开一章和每写十分钟存一个历史版本（每章留 40 版），在“历史版本”里看全文、换回某一版（换之前现在的稿也存一版）；
    删掉的章节，正文也会先存一版。
  - **码字统计**：今天写了多少字（按每天净增算，不算空白、标点算字），设每天的目标，显示连续达标天数。
  - **当书预览、听稿**：作品生成 EPUB 放进书架的“我的作品”分组，用阅读页的排版打开到这一章；“听本章”接着用听书（系统、离线或 AI 语音）读出来，
    读不顺、漏字一听就知道。再预览时刷新同一本书，阅读进度照旧。
  - **导出**：TXT（网文平台常用的格式：段首两个全角空格）、EPUB（带目录，分卷时卷下套章）、Markdown，存到你选的位置。
  - 作品和码字统计跟着灵阅的备份走（历史版本太大，不进备份）；恢复时本机改得更新的作品保留本机的。
- **写作 AI**（可选，用“我的 → AI 助手”里设好的服务商）：在编辑器里点键盘上方的 ✦ 换成 AI 操作。
  - **改稿**：选中文字（不选就是光标所在的那段）润色、更生动、扩写、缩写、挑错、按要求改。
    结果先显示对比（删掉的划线、加上的标绿），可以切到“改后”看全文；点“采纳”才改稿，一步就能撤销。
  - **灵感**：接下来怎么写（三个走向）、细节和描写、起名、卡文了（像编辑一样问你问题）、随便问；只给建议，可以插到光标处。
  - **读者点评**：以网文老读者的眼光说这一章的节奏、看点、弃书风险和三条具体建议。
  - **矛盾检查**：对照设定包和上一章，找人名写法、人物身份、时间线、伏笔前后对不上的地方。
  - **设定包**（作品页 → 设定包）：长篇的资料按类分开放——总纲、不变量、卷纲细纲、硬性设定、人物档案、察觉表、伏笔表、写作规范、称谓与语气、检查规则、技法参考、资料。
    每份文档有优先级（数字小的优先，资料之间有冲突时 AI 以它为准；你在“文风”里写的要求最优先），可设“常用”（每次请 AI 都带上，太长按份数截断）或“按需”；
    每份都有历史版本。可以从文件、整个文件夹或 zip 导入：按文件名自动归类（“人物设定档案”→人物档案、“写作约定”→写作规范、“写手版总纲”比总纲低一级……），
    同名的替换、旧的进历史版本；“已定正文_第1-5章”这类正文文件按章名拆成章节接在最后一卷后面（不算码字数）。整包能导出成 zip，导回来类型和优先级原样还原。
    人物档案新建时带人物卡模板（想要、害怕、怎么说话、标志物、怎么变）；也可以让 AI 从最近写的正文里整理人物，勾选后写进人物档案。旧版的设定集会自动并进设定包。
  - **写作建议**（作品页 → 写作 AI，默认关）：开了以后，你自己写的时候停笔几秒，自动把刚写、改过的段落连同设定包发给 AI，
    按四类找问题：错字（错别字、标点）、设定（和设定包、前文对不上，比如人物已经死了、称呼不对、视角人物不该知道的事）、
    规范（违反写作规范）、口吻（人物说话不像他）。有问题的地方在正文里划线（四类四种颜色），光标点上去，键盘上方显示原因和依据（如“依据：《人物档案》某人”），
    可以“采纳”、“不改”（以后不再提这一条）、“某类不提”（以后不查这一类）。查哪几类、两次至少隔多久（10 秒到 2 分钟）、一天最多发几次可以调，控制花费。
    检查规则（禁用词等）在本机查，不联网，也在正文里标出来。只对开了的那部作品生效；关着时写作不会自动发送任何内容。
  - **学你的文风**：可以写下对文风的要求（如“第一人称，短句为主”）；你采纳过的修改会记下最近 20 条，润色时拿几条当例子，改得更像你。
  - 只在你点了这些功能（或开了写作建议）时联网，发送的是这一章的相关文字和本章资料（按章挑出的设定）；文风要求、设定包、采纳记录只存在本机，随灵阅备份。
- **书签与批注**：顶栏一键加书签；长按选词或划选后点“划线·批注”，可选中一部分划线（四种颜色）、写批注、复制；
  目录面板里集中查看书签和批注，批注可导出为 Markdown。原文件改稿后，批注会按原文重新找回位置。
- **听书**：用系统的文字转语音逐句朗读，正在读的句子高亮并自动翻页、换章；锁屏继续，通知栏可暂停；
  语速可调，可定时关闭（15 / 30 / 60 分钟或本章结束）；可选系统里装好的中文音色；
  显示本章进度和“第几句”，可上一句 / 下一句；耳机线控、蓝牙按键和通知栏都能暂停、切句。
- **书架分组**：长按书籍选“分组…”，一本书可以放进多个分组；书架顶部按分组筛选（全部 / 各分组 / 未分组），
  长按分组标签改名或删除。
- **全书架搜索**：书架搜索框里输入一句话，除了按书名、作者筛选，还能“在所有书的正文里搜索”：
  边搜边出结果，按书分组（每本最多列 20 处），点一处直接打开那本书的那个位置，返回回到结果。
- **书架**：网格或列表显示，按最近阅读、书名、添加时间排序，可搜索书名和作者；书籍详情页显示简介、篇幅、
  累计阅读时长、来源文件等。阅读页底部显示时间和电量。
- **底部导航**：书架、写作、生词本、统计、我的五页，悬浮的液态玻璃导航栏；点标签切换，也可以按住导航栏左右拖动选择；
  不在书架页时返回键先回书架。
- **透明液态玻璃界面**：顶栏、底部导航、对话框、底部面板、下拉菜单、卡片，以及阅读页的菜单栏、听书和自动滚动控制条、
  选字操作条，都是透明的液态玻璃：透出后面的内容，模糊、边缘折射，带高光描边；阅读页的玻璃用书页配色。
  Android 13 起才有（需要 RuntimeShader），更早的系统显示同样布局的纯色界面。
  “我的”里是词典、备份与恢复和关于；书架的排序按钮只管排序和网格/列表显示。
- **备份与恢复**：书架、书籍文件、进度、书签批注、净化规则、设置、生词本、阅读统计、写作的作品，以及每本书的 AI 数据
  （读书笔记、整章翻译、讲书稿、人物表等）打包成一个 zip，换手机时恢复；恢复时本机有而备份里没有的 AI 数据保留。
  书源的下载地址不进备份（有的书源把密钥写在下载链接里），恢复后这些书要从书源重新下载才能“刷新”。
- **自动备份到文件夹**（“我的” → 自动备份到文件夹）：选一个文件夹——可以是云盘、Syncthing 这类同步目录——
  每天自动存一份备份（打开应用或退到后台时检查，先写成 .part 再改名，不会留下半个文件），只留最近 7 份；
  灵阅不做云同步，多台设备之间靠这个文件夹带过去，在另一台上“从备份恢复”。
- **书源**（“我的 → 书源”，或书架右上角“+ → 从书源下载”）：连你自己的书库下载书，不做网页抓取（原因见 [docs/book-sources.md](docs/book-sources.md)）：
  - **OPDS 书目**：Calibre-web、Komga、Kavita 等自建书库，或公版书的古登堡计划（可一键添加）；一层层浏览分类，
    书有封面、作者、简介和可下载的格式，书目支持时可以搜索，分页的书目滚到底自动加载；
  - **WebDAV 文件夹**：NAS、Nextcloud、坚果云、Alist 等，列出子文件夹和灵阅能读的书（大小、修改时间），可以筛选；
  - 点“下载”后和本地导入一样进书架；书架上长按“刷新”会从原地址重新下载，内容变了才更新，进度和批注照旧；
  - 需要登录的填用户名和密码（HTTP Basic 认证），只发给书源所在的那台服务器；密码只存在本机，不进任何备份。
- **用灵阅打开**：在文件管理器、聊天软件里打开或分享上面这些格式的文件，直接导入并开始阅读；
  同一个文件重复打开不会重复入库。分享一大段文字给灵阅时存成一本 TXT。
- **隐私**：不收集任何数据，没有广告和统计；书籍副本只存在本机应用目录。网络权限只给两件事用，都由你操作时才联网、
  直连你设置的地址，不经过任何其他服务器：
  - 书源：浏览、搜索、下载、刷新时连你添加的 OPDS 书目和 WebDAV 文件夹（家里局域网常是 http://，所以允许明文 HTTP）；
  - AI 助手：默认关闭，开启后只在你点 AI 功能时，把这一次需要的文字（选中的文字、查的词和原句、读过部分里的相关原文）
    发给你设置的服务商（只接受 https://）。
  
  AI 密钥和书源密码只存在本机，排除在系统备份、换机迁移和灵阅自己的备份之外，不写日志。
  系统的云备份只带设置、生词本和统计（书、词典、字体、语音模型太大，用灵阅自己的备份）。

## 使用

1. 从 [Actions](../../actions) 下载最新构建的 `LingYueReader-apk`，或自行构建。
2. 点右上角“＋”，选择一个或多个 `.txt` / `.epub` / `.md` 文件。
3. 长按书架上的书可以刷新、重命名或移除。

## 构建

需要 JDK 21 和 Android SDK（compileSdk 37）。界面基于 miuix（HyperOS 风格的 Compose 组件库，`top.yukonga.miuix.kmp:miuix-ui`，导航栏的模糊与折射用 `miuix-blur`）。

```
./gradlew :app:testDebugUnitTest :app:assembleRelease
```

### 签名

正式版用开发者自己的密钥签名，密钥和密码不进仓库。没有密钥时 release 包用 Android 调试签名，照样能装，
但两种签名的包不能互相覆盖安装（换签名要先卸载，卸载前用“我的 → 备份”存一份）。

- **本机**：在项目根目录建 `keystore.properties`（已在 `.gitignore` 里）：

  ```
  storeFile=/path/to/lingyue-release.p12
  storePassword=…
  keyAlias=lingyue
  keyPassword=…
  ```

- **GitHub Actions**：在仓库 Settings → Secrets and variables → Actions 里添加
  `LINGYUE_KEYSTORE_BASE64`（密钥文件的 base64）、`LINGYUE_KEYSTORE_PASSWORD`、`LINGYUE_KEY_ALIAS`、`LINGYUE_KEY_PASSWORD`。
  也可以直接设同名的环境变量，`LINGYUE_KEYSTORE_FILE` 指向密钥文件。

密钥丢了就再也发不出能覆盖安装的更新，务必在离线处多存几份。

## 护眼的依据

- 屏幕越亮、与环境的落差越大越容易疲劳（Benedetto 等，*Computers in Human Behavior* 2014）；晚间屏幕约 21–42 cd/m²、
  环境约 25–50 lx 时疲劳最低（*Applied Sciences* 2021）。深色模式下 10 lx 环境光比全黑疲劳更低，黄色文字最不累、红色最累
  （Fan 等，*Sensors* 2024）。
- 黑字配浅灰底比纯白底舒适；对比度过低反而更累。浅绿底读中文时疲劳指标更好，但证据有限（*Frontiers in Psychology* 2025）。
- 滤蓝光镜片对眼疲劳几乎没有作用，对睡眠的影响也不清楚（Cochrane 系统综述 2023），所以“变暖”只为观感柔和，不宣称护眼或助眠。
- 20-20-20 休息提醒能减轻数字眼疲劳和干眼症状，但停用后效果消失（Talens-Estarelles 等，*Contact Lens and Anterior Eye* 2023）。
- 白字黑底短期内会让脉络膜变厚（Aleman 等，*Scientific Reports* 2018），但能否防近视尚无儿童长期试验，灵阅不做此宣称。
